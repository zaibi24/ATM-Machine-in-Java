# ATM Machine in Java 💳

A simple console-based ATM Machine project built using Java OOP concepts.  
This project allows users to perform basic banking operations like checking balance, depositing money, and withdrawing money.

---

## 🚀 Features

- Check Account Balance
- Deposit Money
- Withdraw Money
- View Account Information
- Simple Menu-driven Interface

---

## 🛠️ Technologies Used

- Java (Core Java)
- Object-Oriented Programming (OOP)
- Scanner Class (User Input)
